# Cryflex

Cryflex is a minimal cryptocurrency exchange simulator built with React, Express, and PostgreSQL. It allows users to register, log in, manage a virtual balance, simulate trades, and review transaction history — all within a clean and responsive interface.

The project focuses on backend consistency, basic trading logic, and a structured fullstack architecture.



## Tech Stack

- **Frontend:** React, Axios
- **Backend:** Node.js, Express, Sequelize  
- **Database:** PostgreSQL



## Key Features

- Secure authentication (JWT)
- Simulated wallet and trade execution
- Transaction history with basic validation
- Clean UI with responsive layout
- Clear code structure (client/server separation)

## Getting Started

To run Cryflex locally:

1. Clone the repository
2. Set up environment variables in `/server/.env` (see `.env.example`)
3. Install dependencies in both `client/` and `server/`
4. Start both servers

Requirements: Node.js, PostgreSQL
